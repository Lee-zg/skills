这不是普通的动画教程 —— 这是一套 **144 个**精心编排的 Agent Skills 🤯，覆盖了迪士尼动画 12 原则在**每一个场景、工具、角色、情绪**下的应用。

## 🎯 12 条动画原则速览

| # | 原则 | 核心理念 | Web 实现方式 |
|---|------|---------|-------------|
| 1 | **挤压与拉伸** | 形变表达重量和弹性 | `transform: scale()` 交互状态 |
| 2 | **预备动作** | 为即将到来的动作做铺垫 | 动作前的微小反向位移 |
| 3 | **演出/舞台** | 引导注意力到重点 | 运动层级 + 背景虚化聚焦 |
| 4 | **逐帧 / 关键帧** | 两种动画创作方式 | JS 逐帧 vs CSS `@keyframes` |
| 5 | **跟随 / 重叠** | 各部分以不同速率运动 | 子元素延迟动画、弹性缓动 |
| 6 | **缓入缓出** | 自然的加减速 | `ease-in-out`、贝塞尔曲线 |
| 7 | **弧线** | 有机曲线运动路径 | `offset-path` 或贝塞尔变换 |
| 8 | **次要动作** | 辅助动作强化主动作 | 阴影、光晕响应主动画 |
| 9 | **节奏** | 速度传达重量和情绪 | 微交互 100-200ms，标准 200-400ms |
| 10 | **夸张** | 超越现实以求清晰 | 超出 1.0 的缩放、过冲动画 |
| 11 | **扎实的造型** | 保持体积和一致性 | 统一 `transform-origin`、透视 |
| 12 | **吸引力** | 魅力和可看性 | 流畅 60fps、有目的的运动 |

## ⏱️ 节奏速查

| 元素 | 时长 | 缓动 | 对应原则 |
|------|------|------|---------|
| 按钮点击 | 100-150ms | `ease-out` | 挤压与拉伸 |
| 悬浮状态 | 150-200ms | `ease-in-out` | 次要动作 |
| 下拉展开 | 200-300ms | `ease-overshoot` | 预备动作 |
| 弹窗进入 | 250-350ms | `ease-decelerate` | 演出/舞台 |
| 弹窗退出 | 150-250ms | `ease-accelerate` | 退出 |
| 页面过渡 | 300-500ms | `ease-standard` | 跟随/重叠 |
| 成功庆祝 | 400-600ms | `ease-elastic` | 夸张 |

## 🧪 CSS 缓动变量

直接复制到你的项目中使用：

```css
:root {
  /* 标准缓动 */
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
  --ease-decelerate: cubic-bezier(0, 0, 0.2, 1);
  --ease-accelerate: cubic-bezier(0.4, 0, 1, 1);

  /* 弹性/活泼 */
  --ease-overshoot: cubic-bezier(0.34, 1.56, 0.64, 1);
  --ease-elastic: cubic-bezier(0.68, -0.55, 0.265, 1.55);
  --ease-pop: cubic-bezier(0.175, 0.885, 0.32, 1.275);

  /* 时长 */
  --duration-instant: 50ms;
  --duration-micro: 100ms;
  --duration-small: 200ms;
  --duration-medium: 300ms;
  --duration-large: 500ms;
  --duration-slow: 800ms;
  --duration-dramatic: 1200ms;
}
```

## ⚠️ 铁律

- 🚫 **永远不要** 对 UI 动画使用 `linear` 缓动（像机器人一样僵硬）
- ♿ **必须** 提供 `prefers-reduced-motion` 无障碍回退
- 🎯 **只动画** `transform` 和 `opacity`（GPU 加速，60fps 保障）
- ❌ **不要动画** `width`、`height`、`top`、`left`（触发重排）
- 📏 微交互 < 200ms，标准过渡 200-400ms，复杂序列 400-700ms
